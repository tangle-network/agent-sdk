# Selected content in the destination request

The full local source previously traveled with every context transfer, including messages and parts the user omitted. Keep the complete `PortableContextPlan` at the caller and send a `PortableContextTransferPlan` with selected typed output and hash commitments to the source and decisions. Compute the accepted plan digest from this commitment representation so the destination can verify the same digest. A request carrying only selected output and an opaque old digest could not verify their relationship; forwarding the full source violated omission semantics. Interface 5 changes the transfer plan shape and digest algorithm. Consumers must create requests through the canonical constructor and adopt the same published contract before live handoff. Legacy operation records need explicit versioned recovery or must finish before upgrading their receiver.
