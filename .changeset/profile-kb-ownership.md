`withProfileKb` now replaces only the block sources it owns. `composeAgentProfileGuidance` takes an optional `replaceSources` for selective replacement (without it, every block is replaced, as in 2.11), and `withProfileKb` owns `harness`, `model`, and `learning` (`PROFILE_KB_SOURCES`), so a team's own guidance layer and blocks a user wrote survive recomposition. The knowledge base adds GPT-6 Astra, Sol, and Luna, which Codex 0.156.1 serves; records Codex 0.156.1, OpenCode 1.18.32, Pi 0.87.1, and Kimi Code 2.0.2; lists the router surface only where a dated router check served the id; drops a comparative line from Claude Haiku 4.5, and composes from a frozen load-time snapshot, so editing an exported record cannot change later compositions (exported types are unchanged). An instruction line counts as composed guidance only when it is one complete block. Direct callers of `composeAgentProfileGuidance` keep the 2.11 behavior; pass `replaceSources` to keep other layers in place. Accepted inputs are unchanged from 2.11: block text may carry an opening marker but not a closing one. `@tangle-network/agent-interface/profile-kb` also exports `composeAgentProfileGuidance` and its types, and Pi cites its vendor CLI and RPC docs.
