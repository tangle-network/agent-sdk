Native session copies ask the Sidecar to leave harness cache and install bytes on the box: `exportRawEvidence` passes `omitContent` with the codex download caches and `.config/opencode/node_modules/`. The list is derived from the same rules that already keep those files as metadata in the capture, and a module-load check refuses a prefix those rules would not keep as metadata. The files stay in the inventory with their metadata. An SDK or Sidecar older than the option sends every byte as before.
